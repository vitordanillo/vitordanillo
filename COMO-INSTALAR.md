# Como instalar o perfil

Crie no GitHub um repositório público chamado exatamente `Zarkzin` dentro da conta `Zarkzin`.

Depois copie estes itens para a raiz do repositório, mantendo a estrutura:

```text
README.md
.github/
  workflows/
    snake.yml
```

Faça o commit na branch `main`. O conteúdo do `README.md` aparecerá automaticamente no seu perfil.

## Ativar a cobra de contribuições

1. Abra a aba **Actions** do repositório.
2. Escolha **Generate contribution snake**.
3. Clique em **Run workflow**.
4. Aguarde a execução terminar e atualize seu perfil.

Se a publicação for bloqueada, abra **Settings → Actions → General → Workflow permissions**, selecione **Read and write permissions** e salve. Depois execute o workflow novamente.
